# Mapped water implementation plan

> **For agentic workers:** Use subagent-driven-development for the independent import and geometry tasks, then integrate and review their outputs.

**Goal:** Render mapped water, slow shallow crossings, and sink the rover with lost-video snow and disabled driving in deep/unknown water.

**Architecture:** One prepared wet mesh feeds rendering, map data, vegetation clearance and an indexed backend contact lookup. A latched backend failure drives both physics and camera state. Preserve schema-1 offline data and existing lifecycle guards.

**Tech stack:** JavaScript modules, Three.js, Rapier, Node test runner, Playwright/Chrome.
